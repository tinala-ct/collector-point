# 🎡 Classroom Lucky Wheel & Score Collector
### วงล้อสุ่มชื่อนักเรียน & ระบบต่อแถวตอบคำถามสะสมคะแนนในชั้นเรียน

เว็บแอปพลิเคชันสำหรับคุณครูและผู้จัดกิจกรรมในห้องเรียน ที่มี 2 รูปแบบกิจกรรมให้เลือกใช้งาน: **โหมดวงล้อสุ่มชื่อ (Wheel Mode)** และ **โหมดเข้าแถวเรียงตอบ (Sequential Character Queue Mode)** พร้อมระบบบันทึกคะแนนสะสม ตอบถูก-ตอบผิด คำนวณสถิติห้องเรียน (Max, Min, Average) และแสดงแท่นรับรางวัล Podium มอบเหรียญรางวัล/ฉายาสุดน่ารัก พร้อมส่งออกผลคะแนนเป็น Excel/CSV ได้ทันที

---

## ✨ ฟีเจอร์เด่น (Key Features)

### 1. 🎮 รองรับ 2 รูปแบบกิจกรรม (Game Modes)
- 🎡 **โหมดวงล้อสุ่มชื่อ (Random Wheel Mode)**: วงล้อหมุนลื่นไหลสไตล์ Wheel of Names พร้อมเสียงติ๊กตามขอบวงล้อและเอฟเฟกต์พลุกระดาษ Confetti
- 🚶 **โหมดเข้าแถวเรียงตอบ (Sequential Character Queue Mode)**: เวทีตัวละคร 3D Clay Figurine สุดน่ารัก (หุ่นดินปั้นสีขาวมินิมอลหลากหลายท่าทาง) มายืนต่อแถวตอบคำถามทีละคน เมื่อตอบถูกหรือตอบผิดจะได้คะแนนแล้ววนไปต่อท้ายแถวเพื่อรอตอบรอบต่อไปอย่างต่อเนื่อง

### 2. 👥 ระบบจัดการห้องเรียน & รายชื่อ
- สลับและเพิ่มห้องเรียนได้ไม่จำกัด (เช่น ม.1/1, ม.1/2)
- เพิ่ม/ลบ รายชื่อ หรือ **วางรายชื่อทั้งห้อง (Bulk Paste)** จาก Excel ได้ใน 1 วินาที
- สลับสถานะเปิด/ซ่อนรายชื่อนักเรียนที่ไม่อยู่ได้ตลอดเวลา

### 3. 🎯 ระบบกติกา & สะสมคะแนน
- กำหนดจำนวนข้อรวมในคาบ (เช่น 10 ข้อ หรือไม่จำกัด) และคะแนนต่อข้อ
- ปุ่มให้คะแนนชัดเจน: **"ตอบถูก (+1 คะแนน)"**, **"ตอบผิด (0 คะแนน)"**, หรือ **"ตอบถูกพิเศษ (+โบนัส)"**
- หากสุ่มเวียนมาเจอนักเรียนคนเดิม คะแนนจะ **สะสมทบต่อเนื่อง** ตลอดทั้งเกม

### 4. 🏆 สรุปผลการแข่งขัน & สถิติวิเคราะห์ (Podium & Cute Awards)
- แท่นรับรางวัล **Podium (อันดับ 1 🥇, 2 🥈, 3 🥉)** พร้อมเหรียญรางวัลและเสียงดนตรี Fanfare
- สรุปค่าสถิติห้อง: **คะแนนสูงสุด (Max)**, **คะแนนต่ำสุด (Min)**, **คะแนนเฉลี่ยห้อง (Average)**, **อัตราการตอบถูก (%)**
- มอบเหรียญฉายาพิเศษน่ารักๆ (🌟 อัจฉริยะประจำคาบ, ⚡ สายฟ้าแลบตอบแม่น, 💖 ขวัญใจกิจกรรม, 🎖️ นักสู้ผู้มุ่งมั่น)

### 5. 📥 ส่งออกผลคะแนน (Export CSV / Print)
- ดาวน์โหลดเป็นไฟล์ Excel/CSV (พร้อม UTF-8 BOM ภาษาไทยไม่เป็นภาษาต่างดาว)
- รองรับการพิมพ์ใบสรุปผล (Print Friendly)

### 6. ⛶ โหมดโปรเจกเตอร์ & 🌙 Dark Mode
- ปุ่ม Fullscreen ฉายขึ้นจอหน้าห้องเรียน
- สลับโหมดมืด/สว่างได้ตามสบายตา

## 🚀 วิธีเปิดเล่นบนเครื่องคอมพิวเตอร์ของคุณ (Local Use)

1. เข้าไปที่โฟลเดอร์ `collector-point`
2. ดับเบิลคลิกเปิดไฟล์ `index.html` ผ่านเว็บเบราว์เซอร์ (Google Chrome, Microsoft Edge, Safari, Firefox)
3. ใช้งานได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมใดๆ เพิ่มเติม!

## 🌐 ขั้นตอนนำขึ้น GitHub Desktop และเปิดใช้งาน GitHub Pages

### ขั้นตอนที่ 1: เพิ่มโปรเจกต์ลงใน GitHub Desktop
1. เปิดโปรแกรม **GitHub Desktop**
2. ไปที่เมนู **File** -> เลือก **Add local repository...**
3. กดปุ่ม **Choose...** แล้วเลือกโฟลเดอร์ `collector-point`
4. กดปุ่ม **Add repository**

### ขั้นตอนที่ 2: Publish ขึ้นไปยัง GitHub
1. กดปุ่ม **Publish repository**
2. ตั้งชื่อ Repository (เช่น `collector-point`)
3. **ยกเลิกการติ๊กถูกที่ช่อง "Keep this code private"** (เพื่อให้เป็น Public Repository ฟรี)
4. กดปุ่ม **Publish Repository** (หรือกดปุ่ม **Push origin** หากเคย Publish แล้ว)

### ขั้นตอนที่ 3: เปิดใช้งาน GitHub Pages
1. เข้าไปที่เว็บ **[GitHub.com](https://github.com)**
2. เปิดเข้าไปใน Repository `collector-point` ของคุณ
3. คลิกแท็บ **⚙️ Settings** -> เมนูด้านซ้ายเลือก **Pages**
4. ในส่วน **Branch** เลือก `main` และ `/ (root)` แล้วกด **Save**
5. คุณจะได้รับ URL สำหรับเปิดเล่น เช่น:
   ```
   https://<your-username>.github.io/collector-point/
   ```

## ⌨️ คีย์ลัด (Keyboard Shortcuts)

- **ในโหมดวงล้อ (Wheel Mode)**:
  - `Spacebar`: หมุนวงล้อสุ่มชื่อ
  - `เลข 1` / `Enter`: บันทึก "ตอบถูก" ในป๊อปอัป
  - `เลข 2` / `Escape`: บันทึก "ตอบผิด" ในป๊อปอัป
- **ในโหมดเข้าแถว (Queue Mode)**:
  - `Spacebar` หรือ `เลข 1`: บันทึก "ตอบถูก (+1)" และส่งไปต่อท้ายแถว
  - `เลข 2`: บันทึก "ตอบผิด (0)" และส่งไปต่อท้ายแถว
  - `เลข 3`: บันทึก "ตอบถูกพิเศษ (+โบนัส)"
