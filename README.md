# 🎡 Classroom Lucky Wheel & Score Collector
### วงล้อสุ่มชื่อนักเรียน & ระบบสะสมคะแนนในชั้นเรียน

เว็บแอปพลิเคชันสำหรับคุณครูและผู้จัดกิจกรรมในห้องเรียน ใช้สุ่มชื่อนักเรียนด้วยวงล้อหมุนที่สวยงาม (สไตล์ Wheel of Names) พร้อมระบบบันทึกคะแนนสะสม ตอบถูก-ตอบผิด คำนวณสถิติห้องเรียน (Max, Min, Average) และแสดงแท่นรับรางวัล Podium มอบเหรียญรางวัล/ฉายาสุดน่ารัก พร้อมส่งออกผลคะแนนเป็น Excel/CSV ได้ทันที

---

## ✨ ฟีเจอร์เด่น (Key Features)

- 🎡 **วงล้อสุ่มชื่อระบบ Canvas 2D**: หมุนลื่นไหล มีเสียงติ๊กตามขอบวงล้อและเสียงเฉลิมฉลอง (Web Audio API ทำงานได้โดยไม่ต้องต่ออินเทอร์เน็ต)
- 👥 **ระบบจัดการห้องเรียน & รายชื่อ**:
  - รองรับการบันทึกแยกห้อง (เช่น ม.1/1, ม.1/2)
  - เพิ่ม/ลบ รายชื่อ หรือ **วางรายชื่อทั้งห้อง (Bulk Paste)** ทีเดียวได้เลย
  - ซ่อน/เปิดใช้งานรายชื่อได้ตามต้องการ
- 🎯 **ระบบกติกา & สะสมคะแนน**:
  - กำหนดจำนวนข้อรวมในคาบ (เช่น 10 ข้อ) และคะแนนต่อข้อ
  - เมื่อสุ่มได้ผู้โชคดี มีป๊อปอัปให้กด **"ตอบถูก (+คะแนน)"**, **"ตอบผิด (0 คะแนน)"**, หรือ **"ตอบถูกพิเศษ (+โบนัส)"**
  - หากสุ่มเวียนมาเจอนักเรียนคนเดิม คะแนนจะ **สะสมทบต่อเนื่อง** ตลอดทั้งเกม
- 🏆 **สรุปผลการแข่งขัน & สถิติวิเคราะห์ (Podium & Cute Awards)**:
  - แท่นรับรางวัล **Podium (อันดับ 1, 2, 3)** พร้อมเหรียญรางวัลและพลุกระดาษ Confetti
  - สรุปค่าสถิติ: **คะแนนสูงสุด (Max)**, **คะแนนต่ำสุด (Min)**, **คะแนนเฉลี่ยห้อง (Average)**, **อัตราการตอบถูก (%)**
  - มอบเหรียญฉายาพิเศษน่ารักๆ (🌟 อัจฉริยะประจำคาบ, ⚡ สายฟ้าแลบตอบแม่น, 💖 ขวัญใจวงล้อ, 🎖️ นักสู้ผู้มุ่งมั่น)
- 📥 **ส่งออกผลคะแนน (Export CSV / Print)**:
  - ดาวน์โหลดเป็นไฟล์ Excel/CSV (พร้อม UTF-8 BOM ภาษาไทยไม่เป็นภาษาต่างดาว)
  - รองรับการพิมพ์ใบสรุปผล (Print Friendly)
- ⛶ **โหมดเต็มหน้าจอ (Fullscreen)** & 🌙 **โหมดมืด (Dark Mode)** สำหรับฉายขึ้นจอโปรเจกเตอร์

## 🚀 วิธีเปิดเล่นบนเครื่องคอมพิวเตอร์ของคุณ (Local Use)

1. เข้าไปที่โฟลเดอร์ `collector-point`
2. ดับเบิลคลิกเปิดไฟล์ `index.html` ผ่านเว็บเบราว์เซอร์ใดก็ได้ (Google Chrome, Microsoft Edge, Safari, Firefox)
3. ใช้งานได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมหรือรันคำสั่งใดๆ เพิ่มเติม!

## 🌐 ขั้นตอนนำขึ้น GitHub Desktop และเปิดใช้งาน GitHub Pages

คุณสามารถนำโปรเจกต์นี้ขึ้น GitHub เพื่อรับลิงก์ URL สำหรับนำไปเปิดเล่นผ่านเว็บหรือแชร์ให้นักเรียนได้ง่ายๆ ตามขั้นตอนดังนี้:

### ขั้นตอนที่ 1: เพิ่มโปรเจกต์ลงใน GitHub Desktop
1. เปิดโปรแกรม **GitHub Desktop** ในเครื่องของคุณ
2. ไปที่เมนู **File** ด้านบน -> เลือก **Add local repository...** (หรือกด `Ctrl+O` / `Cmd+O`)
3. กดปุ่ม **Choose...** แล้วเลือกโฟลเดอร์ `collector-point` นี้
4. *(หาก GitHub Desktop แจ้งว่า This directory does not appear to be a Git repository ให้คลิกที่คำว่า **create a repository** แล้วกดปุ่ม Create Repository)*

### ขั้นตอนที่ 2: Publish ขึ้นไปยัง GitHub
1. กดปุ่ม **Publish repository** (ปุ่มสีฟ้าด้านบน)
2. ตั้งชื่อ Repository (เช่น `collector-point`)
3. **ยกเลิกการติ๊กถูกที่ช่อง "Keep this code private"** (เพื่อให้เป็น Public Repository และสามารถเปิด GitHub Pages แบบฟรีได้)
4. กดปุ่ม **Publish Repository**

### ขั้นตอนที่ 3: เปิดใช้งาน GitHub Pages
1. เข้าไปที่เว็บ **[GitHub.com](https://github.com)** แล้วล็อกอินบัญชีของคุณ
2. เปิดเข้าไปใน Repository `collector-point` ที่เพิ่งอัปโหลด
3. คลิกแท็บ **⚙️ Settings** (แถบเมนูด้านบนของ Repository)
4. เมนูด้านซ้าย เลือกหัวข้อ **Pages** (อยู่ใต้หมวด Code and automation)
5. ในส่วน **Build and deployment**:
   - **Source**: เลือก `Deploy from a branch`
   - **Branch**: เลือก `main` และโฟลเดอร์ `/ (root)`
   - กดปุ่ม **Save**
6. รอระบบประมวลผลประมาณ 1-2 นาที คุณจะได้รับ URL สำหรับเปิดเล่น เช่น:
   ```
   https://<your-username>.github.io/collector-point/
   ```

## ⌨️ คีย์ลัด (Keyboard Shortcuts)

- **Spacebar**: หมุนวงล้อสุ่มชื่อ (เมื่อไม่มีป๊อปอัปเปิดอยู่)
- **เลข 1 / Enter**: บันทึกว่านักเรียน "ตอบถูก" (เมื่อป๊อปอัปคะแนนเปิดอยู่)
- **เลข 2 / Escape**: บันทึกว่านักเรียน "ตอบผิด" (เมื่อป๊อปอัปคะแนนเปิดอยู่)
- **⛶ ปุ่ม Fullscreen**: ฉายวงล้อเต็มหน้าจอสำหรับจอโปรเจกเตอร์หน้าห้องเรียน

## 📁 โครงสร้างโปรเจกต์ (Project Structure)

```
collector-point/
├── index.html              # หน้าเว็บหลัก Single Page Application
├── README.md               # คู่มือการใช้งานและวิธี Deploy
├── css/
│   ├── main.css            # ธีมหลัก, Layout และปุ่มควบคุม
│   ├── wheel.css           # สไตล์วงล้อ Canvas และตัวชี้ Pointer
│   └── scoreboard.css      # สไตล์ตารางคะแนน, Podium, ป๊อปอัป และสถิติ
└── js/
    ├── app.js              # State Management, Game Logic, Modal Controllers
    ├── wheel.js            # Engine วงล้อ Canvas 2D + Deceleration Physics
    ├── audio.js            # Web Audio API สร้างเสียง Ticking/Winner โดยตรง
    ├── confetti.js         # Canvas Confetti พลุกระดาษเฉลิมฉลอง
    ├── storage.js          # จัดการข้อมูล LocalStorage บันทึกห้องเรียนและคะแนน
    └── export.js           # ระบบส่งออกข้อมูล CSV (UTF-8 BOM) และระบบพิมพ์
```
